Gross recovery cannot separate money the agent won from money that would have come back anyway — some failed charges recover on their own when a customer tops up or an issuer stops declining. A randomised slice of cases is therefore held out: detected and diagnosed like any other, then never intervened on. The gap between the arms is the agent's effect.

Not every failure is equally recoverable. An expired card does not un-expire; an empty account often refills by payday.

Every number here is a row count in the database. Two gates sit inside the loop — one before a decision is made, one immediately before it executes — because state can change in between.

Four invariants, enforced in a module that imports neither the policy table nor the model — so a wrong policy cell cannot route around them and no model output can reach them. They run before a decision and again before execution. The counts are live.

The intervention comes from a static table indexed by (failure cause, attempt number). It is total — every cell filled — so the lookup cannot fall through to a default, and every decision records the exact cell it came from.
